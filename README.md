# 拾片

一个给做自媒体的人用的 Chrome 插件：在 B站、抖音、小红书、快手、微博上直接下载视频、图片、封面和字幕，还能批量下载一个博主的作品、导出作品数据表。

- **不用登录插件，不限次数**
- **不连任何第三方服务器**：所有解析和下载都在你自己的浏览器里完成，文件只存在你的电脑上
- **只做免费能拿到的内容**：不接付费的语音识别之类的服务

**[⬇️ 下载最新版安装包](https://github.com/wangyong5609/video-downloader-extension/releases/latest/download/shipian.zip)**　·　[怎么安装](#安装)

> 这是个人自用起步的项目，还在边用边改。下面每项功能后面都标了验证状态，没验证过的会如实写明。

## 能做什么

| 平台 | 单个视频 | 图片 / 图文 | 字幕 | 批量下载 | 作品数据表 |
|---|---|---|---|---|---|
| B站 | ✅ 可选清晰度，自动合并音画 | — | ✅ 需登录 B站 | ✅ | ✅ |
| 抖音 | ✅ 可选清晰度 | 🟡 图文作品 | — | ✅ | ✅ |
| 小红书 | ✅ | ✅ 可转 JPG | — | ✅ | 🟡 字段较少 |
| 快手 | ✅ | — | — | 🟡 | 🟡 |
| 微博 | ✅ | ✅ | — | 🟡 | 🟡 |
| YouTube | — | — | ✅ 原文 / 机器翻译 | — | — |
| 其他网站 | 🟡 嗅探页面里的 mp4 | — | — | — | — |

✅ 实际用过，可用　🟡 已写好，但没有充分验证　— 不支持

几点说明：

- **字幕只有 B站 和 YouTube 有**。抖音、小红书、快手的视频平台本身不提供字幕文件，所以不做。
- **B站 字幕需要浏览器里登录着 B站**，不登录时平台不返回字幕。能选到的最高清晰度也取决于登录和会员状态。
- **YouTube 只下字幕，不下视频**。
- **快手、微博的博主主页需要登录才能看到作品**，没登录时主页批量用不了。
- **不支持有版权保护（DRM）的内容**，也不会尝试绕过。

## 怎么用

### 下载单个视频

在上面这些平台的页面上，把鼠标移到某个视频或作品封面上，右上角会出现一个橙色的下载按钮，点一下就下载这一个（默认最高清晰度）。在 B站 上，下面还有一个白色按钮用来下载字幕。

下载在后台进行，不会打开新的标签页。页面底部会显示进度，插件图标上也有百分比；下完后文件出现在浏览器的下载记录里。

想选清晰度、下载图片或复制文案，点浏览器工具栏上的插件图标，在弹出的卡片里操作。

### 批量下载

1. 打开博主的主页，往下滚动，让作品加载出来。
2. 点页面右下角的“批量下载”，右侧会滑出一个面板。
3. 在面板里勾选作品，选清晰度和下载内容（视频 / 图片、加封面、只要封面），点“下载勾选的作品”。

面板里还可以：

- **按发布日期筛选**（小红书的列表里没有发布时间，所以没有这一项）
- **自动往下翻页**，让原页面持续加载更多作品
- **导出数据表**：把勾选的作品导出成 Excel 能直接打开的 CSV，包含标题、作者、发布时间、时长、点赞、评论、收藏、分享、播放、链接

文件保存在浏览器的“下载”文件夹里，批量下载时按作者分文件夹。

## 安装

目前只支持 Chrome（以及 Edge 等其他 Chromium 内核的浏览器）。插件没有上架 Chrome 商店，需要以“开发者模式”加载。两种装法，选一种就行。

### 方式一：让你的 AI 助手帮你装

如果你在用 Claude Code、Codex、Cursor 这类能操作电脑的 AI 助手，把下面这段话原样发给它：

```text
帮我安装 Chrome 插件「拾片」：
1. 下载安装包：https://github.com/wangyong5609/video-downloader-extension/releases/latest/download/shipian.zip
2. 解压到我的用户目录下的 shipian 文件夹（例如 ~/shipian）。如果这个文件夹已经存在，先清空再解压。
3. 确认这个文件夹里直接就能看到 manifest.json。
4. 把文件夹的完整路径告诉我，然后一步一步带我在 Chrome 里完成最后的加载：
   打开 chrome://extensions → 打开右上角的“开发者模式” → 点“加载已解压的扩展程序” → 选这个文件夹。
5. 提醒我：这个文件夹以后不能移动或删除；已经打开的网页要刷新一下插件才生效。
```

最后“加载”那一步需要你自己点几下鼠标：Chrome 出于安全考虑，不允许任何程序替你悄悄装插件。

### 方式二：自己下载安装

1. 打开 [Releases 页面](https://github.com/wangyong5609/video-downloader-extension/releases/latest)，下载 `shipian.zip`。
2. 解压，得到一个文件夹（里面直接能看到 `manifest.json`）。把它放到一个不会误删的地方，**装好以后不能移动或删除这个文件夹**。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并回车，打开右上角的“开发者模式”。
4. 点左上角“加载已解压的扩展程序”，选择刚才解压出来的文件夹。
5. 已经打开的网页需要刷新一下，插件才会在页面里生效。

建议点一下工具栏上的拼图图标，把“拾片”固定出来，方便使用。

### 更新

下载新版的 `shipian.zip`，解压后覆盖原来的文件夹，回到 `chrome://extensions` 点这个插件卡片上的“重新加载”，再刷新网页。

## 已知的限制

- **单个文件超过约 1.8 GB 下不了**。现在的做法是把文件整个读进浏览器内存再保存，太大的文件会被拦下并提示换低一点的清晰度。
- **B站 多 P 视频批量下载时只下第 1P**。
- **批量列表只包含页面上已经加载出来的作品**，想要更多先在原页面往下滚，或者用“自动往下翻页”。
- **小红书批量下载比较慢**，每篇之间会间隔 2 秒，避免触发平台的验证。
- **平台改版后可能失效**。这些功能依赖各平台网页的内部数据结构，平台一改就需要跟着改。
- m3u8 视频流、实况照片、深色模式写了但没有验证过。

## 它是怎么工作的

没有什么神秘的，三件事：

1. **读网页自己已经拿到的数据**。你打开一个视频页时，网页本身就会向平台请求视频地址，插件只是把这些现成的数据读出来。用的是你自己浏览器里的登录状态，所以你能看的内容它才能下。
2. **在浏览器里合并音画**。B站 的画面和声音是分开传的，插件用网页版的 ffmpeg 把它们合成一个 mp4。
3. **用浏览器自带的下载功能保存**。

## 项目结构

| 文件 | 作用 |
|---|---|
| `manifest.json` | 插件配置 |
| `background.js` | 后台：嗅探视频请求、建立下载任务、给下载请求补上来源信息 |
| `hook.js` | 注入抖音、快手、微博、YouTube 页面，把网页拿到的作品数据抄一份留在页面内存里 |
| `inpage.js` | 页面里的界面：视频上的下载按钮、右下角的批量按钮、右侧面板 |
| `popup.html` / `popup.js` | 点插件图标出现的弹窗 |
| `batch.html` / `batch.js` | 批量下载面板 |
| `offscreen.html` / `offscreen.js` | 后台隐藏页面：下载任务在这里排队执行，不打开标签页 |
| `job.js` | 下载核心：下载、合并音画、保存 |
| `job.html` | 后备方案：后台方式起不来时，退回在标签页里下载 |
| `providers.js` | 各平台取作品列表和下载地址的函数 |
| `shared.js` | 字幕相关的公共函数 |
| `ui.css` | 几个页面共用的样式 |
| `lib/ffmpeg/` | 网页版 ffmpeg（来自 [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm)） |
